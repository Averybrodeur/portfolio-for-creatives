A Very Vegan Bakery

This project designs and builds a full website for A Very Vegan Bakery. The brand, layout, and photography were all created from scratch. The goal is to create a cozy and easy-to-use experience that helps users explore the menu and place orders.

Project Brief

The goal was to build a clear, easy-to-use, and responsive restaurant website in WordPress using Divi. It includes a simple brand, a clean layout, and key pages such as Home, Menu, and Contact. The focus is on strong design, fast loading, and a smooth user experience.

Problem

Small bakeries like A Very Vegan Bakery may not have a clear or easy-to-use website. This can make it hard for customers to view the menu, learn about the brand, and place orders.

Solution

This project creates a clear and easy-to-use website for A Very Vegan Bakery using WordPress. It helps customers view the menu, learn about the brand, and place orders with ease. The design uses simple layouts, warm visuals, and smooth navigation to create a friendly and enjoyable experience.

Reflection

This project was a fun and valuable learning experience that helped me grow as a designer. It was my first time using WordPress and Divi, and adapting to their constraints compared to Figma was challenging but rewarding. I enjoyed creating the branding, photography, and final website, and seeing it come to life gave me a better understanding of real-world design. I look forward to continuing to build my skills through future projects.
