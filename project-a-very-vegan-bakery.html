A Very Vegan Bakery Website Design Case Study

This project designs and builds a full website for A Very Vegan Bakery. The brand, layout, and photography were all created from scratch. The goal is to create a cozy, easy-to-use experience that allows users to quickly browse products and place orders, while reinforcing the bakery’s brand identity.

Project Brief

The goal was to build a clear, easy-to-use, and responsive restaurant website in WordPress using Divi. It includes a simple brand, a clean layout, and key pages such as Home, Menu, and Contact. The focus is on strong design, fast loading, and a smooth user experience.

Problem

Small bakeries like A Very Vegan Bakery may not have a clear or easy-to-use website. This can make it hard for customers to view the menu, learn about the brand, and place orders.

Solution

This project creates a clear and easy-to-use website for A Very Vegan Bakery using WordPress. It helps customers view the menu, learn about the brand, and place orders with ease. The design uses simple layouts, warm visuals, and smooth navigation to create a friendly and enjoyable experience.

Reflection

This project helped me understand what it’s like to design and build a website in a real-world setting. One challenge was adapting my designs from Figma into WordPress using Divi, where I had to work within layout constraints and think more carefully about structure and consistency. Through this, I learned how design decisions affect usability, especially when creating clear navigation and an easy ordering experience. If I were to continue this project, I would focus on testing and refining the user flow to make it even more intuitive. Overall, this project strengthened my ability to design with both user needs and real-world constraints in mind.
